\f0\fs24 \cf0 # ShotPlot\
\
ShotPlot is a competitive rifle shooting logbook and analysis system.\
\
The goal is to help shooters improve performance by recording every aspect of a shooting session and using historical data to provide meaningful recommendations.\
\
## Current Features\
\
- Rifle management\
- Zero book\
- Match management\
- Firestring management\
- Shot plotting\
- Printable firestring reports\
- Rifle history\
- Match summary\
- Sight adjustment log\
- Automatic score calculation\
- Group analysis\
- Environmental conditions\
\
## Technology\
\
- Laravel 13\
- PHP 8.5\
- SQLite (development)\
- Bootstrap 3 (current UI)\
\
## Future Direction\
\
ShotPlot is being designed around a shared data model that will support:\
\
- Desktop web application\
- Tablet application\
- Offline range operation\
- AI-assisted recommendations\
\
The long-term objective is to become a complete shooting data system rather than simply a scorebook.\
\
## Current Status\
\
Early Beta\
\
Primary emphasis is on feature completeness before UI modernization.}
